Offline speech models are stored here.

Recommended presets:

- `vosk-model-small-vn-0.4`
- `vosk-model-small-en-us-0.15`

Quick setup:

```bat
setup_offline_voice.bat
```

Manual layout:

```text
models/
  vosk-model-small-vn-0.4/
  vosk-model-small-en-us-0.15/
```

The dashboard offline voice panel can switch between these model folders by path.
